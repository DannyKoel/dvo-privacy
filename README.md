# DVO privacyverklaring

Zelfstandige statische privacyverklaring voor Dartvereniging Oost-Nederland, inclusief de Facebookkoppeling van het CMS.

Publicatie via GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root) → Save.

Beoogde URL: https://dannykoel.github.io/dvo-privacy/

De pagina bestaat uit index.html met ingebedde opmaak en DVO-logo. Geen buildstap, externe scripts, tracking of configuratiegeheimen. Wijzigingen worden rechtstreeks in index.html bijgehouden. Na tekstwijzigingen ook de genoemde versiedatum beoordelen.

De oorspronkelijke bron van het algemene privacyhoofdstuk is https://www.dvodarts.nl/reglementen/#privacy-policy . De passages over derden en verwerking buiten de EU zijn verduidelijkt voor de Facebookkoppeling en GitHub Pages. De vereniging is verantwoordelijk voor de inhoud en het actueel houden van deze verklaring.
